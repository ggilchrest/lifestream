# Record Explorer keeps the latest refresh

In Records, starting another refresh prevents an older response from replacing the newer record list and revision. Errors from an earlier refresh no longer interrupt the current view. If the latest refresh fails, its error is still shown; use **Refresh Records** to retry. Changing your account, Assistant or relationship clears the previous selection's records.

The isolated candidate passed six focused synthetic regression checks and three browser cases in disposable fixtures on November 16, 2026. These checks used synthetic records; live-backend validation remains separate. This change has not been released or deployed.
