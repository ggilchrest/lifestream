# Incident media cleanup

Conversation reviews authorized PWCE incident summaries and retained media through the pinned public contract. Reviewing evidence does not activate capture or grant a device permission.

Close retained media cancels the pending media request, invalidates its reply and stops/releases any loaded video before removing it. A new explicit review may load it again. Hide incident evidence, audience/identity/session changes, leaving Conversation, hidden-page and page-exit cleanup apply the same stopping behavior to every card. A stale download or error cannot reopen a closed card or overwrite the state of a later review.

The browser regression uses disposable metadata, real HTTP and a generated, decoded WebM clip; it captures no camera/microphone input. Existing authenticated producer/consumer contract checks remain separate. Actual clips, native player controls and physical/Human playback acceptance are not implied by synthetic playback evidence.
