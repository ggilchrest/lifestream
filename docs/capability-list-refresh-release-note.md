# Capability lists keep the current refresh result

In **Capabilities & actions**, an earlier refresh of Requests or Grants no longer replaces the latest result with a stale error or an incorrect “loaded” message. Errors from the current refresh are still shown, and you can refresh again to retry. A failed permission refresh retains the existing unavailable message.

Pagination and filters retain their existing behavior. Refreshing a list does not approve a request, grant permission or run an action.

The isolated candidate passed independent source review, eight focused synthetic checks and three browser cases in disposable fixtures on November 16, 2026. Live-backend validation remains separate. This change has not been released or deployed.
